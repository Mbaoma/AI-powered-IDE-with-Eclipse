# Sample workspace

Opened automatically by `scripts/start.sh` to exercise each bundled language toolchain. Try it from the browser IDE:

- **Node.js**: open `hello.js`, open a terminal (``Ctrl+` ``) and run `node hello.js`.

- **Python**: open `hello.py`, run `python3 hello.py` in the terminal.

- **Java**: open `Hello.java`, run `javac Hello.java`.
