# Sample workspace

Opened automatically by `scripts/start.sh` to exercise each bundled language toolchain. Try it from the browser IDE:

- **Node.js**: open `hello.js`, open a terminal (``Ctrl+` ``) and run `node hello.js`, or press F5 and pick "Debug hello.js (Node)" to hit a breakpoint.
- **Python**: open `hello.py`, run `python3 hello.py` in the terminal, or press F5 and pick "Debug hello.py (Python)". Requires `python3` on your PATH (already the case on this machine).
- **Java**: open `Hello.java`. Language features (completion, errors, "Debug Hello.java") only activate once a JDK is installed and on your PATH — see the root README's "Prerequisites" section.
